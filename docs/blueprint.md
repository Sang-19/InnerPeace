# **App Name**: WellTrack

## Core Features:

- Secure User Authentication: Secure authentication system with role-based access (admin/student) using Firebase Auth.
- Student List & Management: Display and manage a list of students, including their profile information and mental health status.
- Community Reports Monitoring: Monitor and manage community reports for harmful content, allowing admins to take necessary actions.
- AI Chatbot Assistance: Provide 24/7 conversational support and guidance to students using a Gemini-powered chatbot tool. This chatbot will use stored emergency contact information to assess when a student needs emergency intervention.
- Mood Tracking and Visualization: Allow students to track their daily mood and visualize trends over time using charts and graphs.
- Relaxation and Mindfulness Exercises: Provide access to guided relaxation techniques and mindfulness exercises.
- Emergency Alert System: Enable students to send immediate emergency alerts to admins with one click.

## Style Guidelines:

- Background color: Light grayish-blue (#E0E5EB) for a calming and neutral backdrop.
- Primary color: Soft blue (#77A1D3) to promote feelings of trust and serenity.
- Accent color: Gentle violet (#B18CD9) for highlights and interactive elements, suggesting peace and balance.
- Font: 'Inter', a sans-serif font for clear and accessible readability in both headlines and body text.
- Use simple, clear, and accessible icons to represent various features and actions within the app.
- Maintain a clean, uncluttered layout with ample whitespace to reduce visual stress and improve focus.
- Incorporate subtle, soothing animations for transitions and feedback to create a smooth and calming user experience.
